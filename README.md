# ⚡ Syndicate KB Responder & Cadence Mesh Engine (v1.0)

Интеллектуальный тактический генератор контекстных реплик и возражений для Telegram-клоузеров и арбитражных связок, построенный на базе базы знаний **Syndicate Intelligence** (7 модулей институционального арбитража).

Движок решает проблему оверпрайса и галлюцинаций LLM при работе с тяжелыми учебниками: вместо скармливания 85,000–100,000 токенов каждого модуля в промпт, система выполняет **хирургическую структурную нарезку Markdown (AST Slicing) + локальный поиск SQLite FTS5 + масштабирование юнит-экономики под депозит лида + генерацию через префиксное кэширование DeepSeek v4.1** (стоимость ответа ~$0.00025, инференс < 2.5 сек).

## 🚀 Ключевые возможности

### 1. Хирургическая нарезка Markdown (AST Slicing)
* Парсер разбирает заголовки модулей `M01–M07`, выделяя:
  * **Слои:** L1 (Retail Illusion), L2 (Mechanics), L3 (Institutional Reality), L4 (Formulas/Math), L5 (Code/HFT).
  * **Боевые карточки возражений:** C01–C10 (тезисы, триггеры, контраргументы, аналогии).
  * **Глоссарий терминов:** 196+ институциональных определений.
* Фильтрует тяжелый исходный C++/Python/Solidity код и формулы, снижая нагрузку на контекст в 50 раз.

### 2. Локальный поиск SQLite FTS5 (BM25)
* Мгновенный полнотекстовый поиск с ранжированием BM25 по срезам, слоям и карточкам.
* Индексация всех 7 учебников занимает < 1 сек.
* Генерация читаемых сниппетов совпадений.

### 3. Масштабирование юнит-экономики (`UnitEconScaler`)
* Динамически адаптирует цифры доходностей, комиссий, проскальзываний и сетевых сборов под рабочий депозит:
  * **Micro ($20):** Проверочный круг по плейбуку `Fast Track Closer` (+$0.70 на балансе).
  * **Retail ($500–$2,000):** Бытовые комиссии Bybit/OKX, чистый спред 1.2–1.8%.
  * **Mid ($5,000–$15,000):** Лимиты вывода CEX, учет глубин стаканов, T+1 задержки.
  * **Whale ($50,000+):** OTC-дески, темные пулы ликвидности, кредитное плечо.

### 4. Генерация матриц ответов (DeepSeek v4.1 via OpenRouter)
* **Паблик-хуки (`hook`):**
  * Генерирует матрицу из 3 тактических углов за один запрос:
    * **Вариант 1 (Согласие + Инсайд):** Встает на сторону автора, подтверждает реальность риска, дает инсайдерский нюанс.
    * **Вариант 2 (Технический разбор):** Механика спреда, фандинг, задержки ребалансировки ног, разбор без воды.
    * **Вариант 3 (Вопрос-триггер в ветку):** Короткая реплика с точным техническим вопросом, вовлекающим в диалог.
  * Строгий анти-питч: никаких упоминаний $20, никаких предложений заработка, никаких приглашений в ЛС.
* **ЛС-щиты (`shield`):**
  * Строгая эскалация по стадиям воронки (`In_DM` $\to$ `Legend_&_Media` $\to$ `Test_20` $\to$ `Volume_500_2k`).
  * На этапе `In_DM` — никаких запросов баланса/скринов, квалификация по рабочим биржам (Bybit, OKX).
  * На этапе `Legend_&_Media` — легенда: ферма физических iPhone ($150–$200), Apple Secure Enclave (`App Attest`), лимит 4 круга в день по цифровой гигиене.
  * На этапе `Test_20` — проверочный круг $20 со своего CEX на азиатскую ноду, вывод прибыли на кошелек лида.

## 🛠 Установка и настройка

```bash
# 1. Клонирование репозитория
cd syndicate-kb-responder

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Настройка окружения
cp .env.example .env
# Заполните OPENROUTER_API_KEY и KB_ROOT_DIR в файле .env
```

## 💻 Использование CLI

```bash
# Индексация базы знаний
python cli.py index

# Поиск по базе знаний
python cli.py search "фандинг ликвидация" --layer L2 --limit 3

# Масштабирование текста под депозит $20
python cli.py scale "Спред 1.5% дает чистыми $15 с оборота $1000" --deposit 20

# Генерация матрицы из 3 хуков для паблик-чата
python cli.py hook --context "Меня на фандинге выбило в лонге по SOL" --author "trader123" --deposit 1000

# Генерация ответа на возражение в ЛС с учетом стадии воронки
python cli.py shield "А почему вы сами не гоняете на всю котлету?" --stage "Legend_&_Media" --deposit 1500

# Бенчмарк производительности и стоимости
python cli.py bench
```
